# Описание доменных сущностей проекта «Ромашка»
Описание взято из внешнего источника:
https://github.com/Dest1n640/Design-Patterns/blob/main/_docs/DomainEntities.md

## 1. Общие сквозные сущности

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **Организация** | `ООО Ромашка` — юридическое лицо, владеющее сетью ресторанов | Владеет всеми `Ресторан`; выступает стороной в `Контрагент`-отношениях |
| **Ресторан** | Точка сети, 10 шт.; атрибуты: адрес, тип работы — доставка, комбинированный или зал; режим 10:00–22:00 | Связан со `Склад`; связан с `Сотрудник` через штат; связан с `ЗаказНаДоставку`, `ЗаказНаПополнениеСклада` |
| **Помещение** | Физическое пространство, в котором расположен склад | Связь со `Склад` |
| **ПроизводственныйЦех** | Отдельное подразделение, работает круглосуточно, готовит заготовки и хранит централизованно закупаемые мясные и молочные продукты | Имеет собственный `Склад`; выполняет `ПриготовлениеПолуфабриката`, `ПриготовлениеБлюда`, `ВыпускПродукции`; отгружает по `ЗаказНаПополнениеСклада` |

---

## 2. Складской учёт

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **Номенклатура** | Единица учёта товара, сырья, полуфабрикатов и готовых блюд. Атрибут «тип позиции»: сырьё / товар / полуфабрикат / блюдо | Входит в `ГруппаНоменклатуры`; участвует в `ОстатокНоменклатуры`; используется в `ТехнологическаяКарта` (как сырьё и как результат), в `Инвентаризация`; удаление блокируется, если позиция задействована в складском учёте (п. 6.2 ТЗ) |
| **ГруппаНоменклатуры** | Классификатор номенклатуры | Объединяет `Номенклатура`; используется в частичной `Инвентаризация` по группе; удаление блокируется, если в группе есть номенклатура, участвующая в учёте (п. 6.2 ТЗ) |
| **Склад** | Место хранения остатков | Связан с `Помещение`; привязан к `Ресторан` или `ПроизводственныйЦех`; содержит `ОстатокНоменклатуры` |
| **ОстатокНоменклатуры** | Регистр: количество номенклатуры на конкретном складе | Ссылается на `Склад` и `Номенклатура`; изменяется документами `ВыпускПродукции`, `УтилизацияПродукции`, `СписаниеНоменклатуры`, `Инвентаризация` |
| **Инвентаризация** | Документ пересчёта остатков; виды: плановая — ежемесячно по всей номенклатуре, и частичная — по группе, несколько раз в месяц; содержит перечень позиций (номенклатура, учётное и фактическое количество) | Ссылается на `Склад`, опционально на `ГруппаНоменклатуры`; фиксирует ответственного `Сотрудник` |

## 3. Производственный учёт

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **ТехнологическаяКарта** | Рецепт или спецификация приготовления; может быть составной — допускает включение одной технологической карты в состав другой; описывает состав используемой номенклатуры-сырья и итоговую номенклатуру-результат (полуфабрикат или блюдо) | Рекурсивная связь сама с собой; ссылается на `Номенклатура` (сырьё и результат) |
| **ПриготовлениеПолуфабриката** | Документ операции приготовления полуфабриката | Ссылается на `ТехнологическаяКарта`, списывает `Номенклатура` (сырьё) со `Склад`, фиксирует ответственного `Сотрудник` |
| **ПриготовлениеБлюда** | Документ операции приготовления блюда | Аналогично `ПриготовлениеПолуфабриката`; может использовать готовые полуфабрикаты (`Номенклатура` с типом «полуфабрикат») как сырьё |
| **ВыпускПродукции** | Документ оприходования готовой продукции на склад | Увеличивает `ОстатокНоменклатуры`; ссылается на `Номенклатура` (произведённую позицию), `Склад`, `Сотрудник` |
| **УтилизацияПродукции** | Документ списания бракованной или непригодной продукции | Уменьшает `ОстатокНоменклатуры`; ссылается на `Номенклатура`, `Склад`, `Сотрудник` |
| **СписаниеНоменклатуры** | Документ списания сырья при производственных операциях; вариант списания — «с блокировкой»: запрет при недостатке остатка, или «под сальдо»: без блокировки, остаток может уйти в минус | Ссылается на `Номенклатура`, `Склад`; порождается операциями раздела 3 |

## 4. Курьерская служба

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **РайонДоставки** | Географический район с фиксированной стоимостью доставки | Используется в `ЗаказНаДоставку` для расчёта стоимости |
| **МенюДоставки** | Отдельное от зального меню, действующее только для доставки; содержит перечень позиций (блюд из `Номенклатура`), доступных для заказа на доставку | Привязано к `Ресторан`, работающему на доставку; используется в `ЗаказНаДоставку` |
| **ЗаказНаДоставку** | Заказ клиента на доставку | Привязывается к ближайшему подходящему `Ресторан` по `РайонДоставки`; содержит позиции из `МенюДоставки`; фиксирует ответственного `Сотрудник`; относится также к оперативному учёту, раздел 7 |

## 5. Финансовый учёт

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **Контрагент** | Юридическое лицо — сторона расчётов | Входит в `ГруппаКонтрагентов`; участвует в `Поступление`, `Списание` |
| **ГруппаКонтрагентов** | Классификатор контрагентов | Объединяет `Контрагент` |
| **ТипОплаты** | Справочник способов оплаты: наличные, банковский перевод и прочее | Используется в `Поступление`, `Списание` |
| **Поступление** | Документ поступления денежных средств | Ссылается на `Контрагент`, `ТипОплаты`, ответственного `Сотрудник` |
| **Списание** | Документ списания денежных средств; не путать со `СписаниеНоменклатуры` из раздела 3 | Ссылается на `Контрагент`, `ТипОплаты`, ответственного `Сотрудник` |

## 6. Учёт персонала

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **Сотрудник** | Работник компании; категория: производство, обслуживание или управление | Работает в `Ресторан` или `ПроизводственныйЦех`; связан с `ГрафикРаботы`; указывается как ответственный почти во всех документах системы; удаление карточки блокируется, если сотрудник участвовал в складском, оперативном или финансовом учёте (п. 6.3 ТЗ) |
| **КатегорияСотрудника** | Справочник категорий: производство, обслуживание, управление | Объединяет `Сотрудник` |
| **ГрафикРаботы** | График с составом смен; для производства — индивидуальный, смены до 8 ч, для прочих категорий — типовой, 8 ч/день, кроме выходных и праздников | Содержит `Смена`; связан с `Сотрудник`, включая случай общего графика на нескольких сотрудников |
| **Смена** | Плановый интервал работы в рамках графика | Ссылается на `ГрафикРаботы` |

---

## 7. Оперативный учёт

| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **ЗаказНаДоставку** | См. раздел 4 — также относится к оперативному учёту как направление контроля | — |
| **ЗаказНаПополнениеСклада** | Заявка ресторана в производственный цех на поставку заготовок и централизованных продуктов | Ссылается на `Ресторан` — заказчик, `ПроизводственныйЦех` — исполнитель, `Номенклатура`, ответственного `Сотрудник` |
| **ЗаказНаПроизводство** | Внутренняя заявка на изготовление продукции | Ссылается на `ТехнологическаяКарта`, `ПроизводственныйЦех`, ответственного `Сотрудник` |
